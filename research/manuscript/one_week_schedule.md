# Seven-day initial-draft schedule

| Day | Non-negotiable deliverable |
| --- | --- |
| 1 | Freeze ontology, protocol, deterministic manifests, and manuscript structure. |
| 2 | Complete first independent annotation pass for the 320-clause corpus. |
| 3 | Complete second annotation pass and start reconciliation; fix prompt on pilot corpus only. |
| 4 | Run and archive three extraction methods on the adjudicated corpus. |
| 5 | Review compliance cases independently, run evaluation, and generate figures/tables. |
| 6 | Replace all result placeholders, insert 35–45 verified references, and complete Results/Discussion. |
| 7 | Full manuscript edit, reproducibility rerun, reference audit, and supervisor-ready PDF/DOCX export. |

## Daily stopping rule

If a numerical result has not been generated from the archived experiment output, leave it marked `[TBD]`. A complete honest draft is preferable to a polished but unsupported claim.
