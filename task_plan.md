# SCI manuscript sprint plan

## Goal

Produce a defensible English first draft and the reproducible experimental assets for the building-code knowledge-graph study within seven calendar days. No performance value may be fabricated.

## Phases

| Phase | Status | Deliverable |
| --- | --- | --- |
| 1. Research protocol | complete | Ontology, annotation guide, sample manifest, case suite |
| 2. Experiment tooling | complete | Sampling and evaluation scripts |
| 3. Manuscript draft | complete | English Markdown manuscript with evidence-bound placeholders |
| 4. Verification | pending | Dataset/case checks and buildable script checks |
| 5. Literature and results fill | pending | Verified references and real experiment outputs |
| 6. Figure design | complete | Python-generated publication-style flowchart board |
| 7. Recent reference package | complete | 20 recent ACC/BIM/KG/LLM references with metadata, BibTeX, notes, and available OA PDFs |

## Non-negotiable rules

- Existing demo graph records are not LLM evaluation data.
- Empty or unverified metrics remain explicit placeholders.
- LLM configuration and prompt versions must be preserved with outputs.
